1. A pseudo-element is a CSS feature that lets you style a specific part of an element or insert generated content without changing the HTML.
  2. Syntax: selector::pseudo-element { ... }. Common ones: ::before, ::after, ::first-line, ::selection.

Position

static (default): normal flow; top/left/right/bottom and z-index do not apply.
relative: offset from normal flow; creates positioning context.
absolute: removed from flow; positioned relative to nearest non-static ancestor.
sticky: behaves like relative until scroll threshold, then like fixed (top: 0 here).
fixed: positioned relative to viewport (bottom-right corner).

Display

block: takes full width, starts on a new line.
inline: flows within text; width/height ignored. More text here to show inline behavior.
inline-block: respects width/height and sits inline with text.

Overflow

z-index controls the stacking order (which element appears on top) of positioned elements (position other than static). Higher z-index → appears above lower z-index in the same stacking context. Stacking context: Created by certain properties/combinations, commonly position: relative/absolute/fixed/sticky with a non-auto z-index. Inside a stacking context, children (including pseudo-elements) are ordered by z-index and DOM order. Default order for an element with pseudo-elements (simplified): ::before, element’s background/border and in-flow content, ::after. To place a pseudo-element behind its parent’s content: Give the parent a stacking context (e.g., position: relative; z-index: 1). Set the pseudo-element to position: absolute (or relative) and a negative z-index (e.g., -1).
